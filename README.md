# Simon Bastide - data engineer · Cévennes, France

Co-founder of **IOTA**, where we help small businesses and local government find
where they lose time, money or reliability, then build the simplest thing that
fixes it. Automation, data, AI where AI is the right lever - and sometimes no
technology at all.

I came to data during a biomechanics PhD, trying to process human movement
recordings that were too large and too messy for the tools I had. That problem
turned out to interest me more than the research question. Since then I have
moved one step upstream at every stage: from analysis to data, from data to
infrastructure, from infrastructure to how organisations actually work.

## Method

A few rules, mostly there to stop me from building too early:

- A request is not a problem.
- A tool is never a goal.
- No solution before understanding the real process.
- Any problem worth solving has a measurable consequence.
- Remove before automating.
- The simplest solution that works wins.
- Concluding that nothing should be built is a valid outcome.

The solution space, in order - stop at the first rung that holds:

`remove` → `change the process` → `standardise` → `give them a tool` → `automate` → `data / AI`
